# 다음 역은 없습니다 — 웹 프로토타입

> 이 파일은 현재 프로토타입 실행/조작 안내입니다. 목표 규칙과 요구사항의 정본은 [게임 기획 문서](../game-design/README.md)입니다.

심야 지하철 안내실에서 CCTV, 운행표, 통화 기록을 대조하고 안내 방송 여부를 판단하는 짧은 공포 게임 프로토타입입니다.

## 실행

index.html을 최신 브라우저에서 열면 됩니다. 설치나 서버, 외부 이미지·라이브러리는 필요하지 않습니다.

## 조작

- 각 호출에서 오른쪽 선택지를 눌러 방송하거나 침묵합니다.
- 1–3 키로 선택하고 Enter로 다음 호출로 넘어갈 수 있습니다.
- CCTV 카메라와 운행표, 통화 기록을 오가며 정보를 확인합니다.
- 오른쪽 위 소리 버튼은 선택 사항이며 기본값은 꺼짐입니다.

총 5건의 호출이 이어지며, 근무 기록과 방송실 잔향에 따라 결과 문구가 달라집니다.
