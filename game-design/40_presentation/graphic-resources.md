## 1. 목적과 기준

이 문서는 첫 번째 근무를 제작하는 데 필요한 그래픽 리소스, 파일 규칙, 우선순위와 VFX 스프라이트 시트 사양을 정한다. ImageGen으로 만든 래스터 시안과 별도 SVG 아이콘은 [생성 에셋 목록](../assets/README.md)에 있다. 전체 배경 교체 방식의 시안이며, 아래의 분리 레이어/정확한 VFX 규격을 모두 충족한 최종 게임 에셋은 아니다.

현재 프로토타입의 역 장면은 game.js 안의 간단한 SVG 도형으로 그려져 있다. 이를 완성 아트로 보지 않고, 아래 목록의 “프로토타입 임시 리소스”를 데이터 참조가 가능한 에셋으로 분리하는 것을 목표로 한다.

### 화면 기준

- CCTV 기준 좌표: **720×405, 16:9**
- UI 크기는 CSS로 반응형 조정하고, 장면 아트는 동일한 16:9 기준 좌표로 렌더링한다.
- 카메라 시각 정보와 모든 한글 문구는 UI/콘텐츠 데이터로 표시한다. 배경 이미지에 글자를 굽지 않는다.
- 장면 요소는 데이터에서 켜고 끌 수 있도록 배경, 소품, 인물, 조명/VFX 레이어를 분리한다.
- 권장 제작 원본은 SVG. VFX 애니메이션은 투명 PNG 스프라이트 시트와 프레임 메타데이터를 사용한다.

## 3. 환경 및 소품 분리 사양

### 배경 레이어

각 CCTV 환경은 다음 레이어로 나눈다.

1. **BG:** 벽, 바닥, 원근, 터널/복도 기본 구조
2. **ARCH:** 기둥, 문틀, 선로 등 장소 구조물
3. **PROP:** 셔터, 벤치, 전광판, 전화기 등 사건에 따라 상태가 달라지는 소품
4. **ACTOR:** 승객/이상 인물 실루엣
5. **LIGHT/VFX:** 조명 변화, 신호 간섭, 사건 반응

레이어는 SVG 그룹 또는 별도 에셋 참조로 불러온다. 장면 데이터를 바꾸면 셔터 열림/닫힘, 안내등, 표지판 정보, 인물 유무를 교체할 수 있어야 한다.

### 필수 소품 변형

| 소품 | 상태 |
|---|---|
| 2번 출구 셔터 | 잠김, 열림 |
| 출구/목적지 표지판 | 정상 문구, 정보 없음/빈 칸 |
| 승강장 전광판 | 운행 취소, 도착 문구, 빈 화면 |
| 형광등 | 안정, 짧은 점멸, 꺼짐 |
| 역무실 출입문 | 잠김, 열린 틈 |
| 승객 실루엣 | 먼 거리, 노란 선 가까이, 한 걸음 물러남 |
| 승강장 이상 흔적 | 젖은 레일, 젖은 손자국, 추가 인원 표시, 얼굴 소실 |
| 복도 이상 인물 | 숨김, 원거리 출현 |

상태별 아트는 독립된 이미지 전체를 중복 제작하기보다, 공통 배경 위에 소품/상태 레이어만 교체한다. 선택으로 생긴 셔터·문·인물·흔적 상태는 호출이 바뀐 뒤에도 보일 수 있어야 한다. 일시적인 열차 불빛은 다음 호출 전에 사라지지만 젖은 레일 상태는 남는다.

## 4. VFX 스프라이트 시트 사양

### 파일

- **이름:** vfx-cctv-atlas-v01.png
- **메타데이터:** vfx-cctv-atlas-v01.json
- **포맷:** PNG RGBA, 투명 배경
- **프레임:** 128×128px
- **배치:** 가로 8열 × 세로 6행, 총 48프레임
- **시트 크기:** 1024×768px
- **프레임 순서:** 각 행의 왼쪽에서 오른쪽으로 재생
- **셀 여백:** 각 프레임 가장자리 안쪽에 4px 투명 안전 여백
- **색상:** 장면에 얹어도 단서와 텍스트를 가리지 않는 저채도 회녹색/회백색. 위험 강조용 붉은색은 필요한 프레임에만 제한
- **텍스트 포함 금지:** 방송 문구, 시각, 카메라 라벨은 런타임 UI에서 렌더링

### 행별 애니메이션

| 행(0부터) | 효과 ID | 프레임 | 재생 | 합성/기준점 | 사용 목적 |
|---:|---|---:|---|---|---|
| 0 | FX-SCREEN-TEAR | 8 | 12fps, 1회 재생 | Normal, 화면 전체에 맞춤 | 잘못된 방송 뒤 CCTV 프레임이 찢어지는 간섭 |
| 1 | FX-SIGNAL-NOISE | 8 | 12fps, 1회 재생 | Normal, 화면 전체에 맞춤 | 신호가 끊기거나 비정상 장면이 나타날 때 |
| 2 | FX-BROADCAST-RIPPLE | 8 | 10fps, 1회 재생 | Screen/Lighten, 중심 기준 | 방송이 역의 장면에 전달되는 파동 |
| 3 | FX-SHADOW-REVEAL | 8 | 8fps, 1회 재생 | Normal, 하단 중앙 | 실루엣이 화면의 어둠에서 드러나는 순간 |
| 4 | FX-LAMP-FLICKER | 8 | 12fps, 짧게 1회 | Lighten, 조명 중심 | 형광등이 불안정해졌다가 상태를 확정하는 반응 |
| 5 | FX-DUST-STATIC | 8 | 8fps, 최대 2초 반복 | Normal, 작은 크기로 반복/타일 | CCTV 정적의 미세한 입자. 기본 화면에는 약하게만 사용 |

스프라이트 런타임은 행과 프레임 수를 읽어 재생한다. 화면 전체에 확대하는 효과는 장면 단서를 덮지 않도록 알파와 재생 시간을 제한한다. 광량이 급격히 반복되는 연출은 피하고, 움직임 줄이기 설정에서는 애니메이션을 끄거나 정지 프레임으로 대체한다.

### 메타데이터 필드

메타데이터는 각 효과에 다음 항목을 제공한다.

- effectId, sheet 경로
- frameWidth/frameHeight, columns/rows
- row, startColumn, frameCount
- fps, loop 또는 playOnce
- blendMode, anchor, 기본 scale/alpha
- triggerId와 재생 후 상태
- reducedMotionFallback: 숨김 또는 정지 프레임 ID

### 호출별 VFX 연결

| 호출 | 트리거 | 적용 효과 | 주의 |
|---|---|---|---|
| 닫힌 출구 | 잘못된 개방 방송 | FX-SCREEN-TEAR 후 셔터 상태 변경 | 배경 전체가 아니라 셔터 주변을 먼저 읽히게 한다 |
| 없는 열차 | 도착 방송 또는 검증된 취소 방송 | 도착 방송은 FX-SIGNAL-NOISE, 취소 방송은 약한 FX-BROADCAST-RIPPLE | 열차 불빛은 일시 소품 상태, 젖은 레일은 지속 소품 상태로 처리 |
| 노란 선 너머 | 안전 방송/열차 도착 방송 | 안전 방송은 FX-LAMP-FLICKER 후 안정, 열차 도착 방송은 FX-SHADOW-REVEAL | 인물 이동이 핵심 단서이므로 이펙트로 가리지 않는다 |
| 퇴직자의 내선 | 직원 도착 방송 | FX-SHADOW-REVEAL | 방송 보류는 화면을 과하게 흔들지 않고 음향/통화 기록으로 반응 |
| 마지막 안내 | 종료 문구 방송/다른 문구 방송 | 기준 문구는 FX-BROADCAST-RIPPLE, 다른 방송은 FX-SCREEN-TEAR | 결말 텍스트의 가독성을 유지한다 |

## 5. 아이콘과 UI 그래픽

UI-01 아이콘은 선 굵기 1.5–2px를 기준으로 하고, 24px와 32px 크기에서 식별 가능해야 한다. 아이콘만으로 의미를 전달하지 않고 접근 가능한 이름과 문구를 함께 쓴다.

필수 아이콘:

- CCTV/카메라
- 운행표/열차
- 통화/전화 수신
- 안내 마이크/송출 중
- 무음/침묵
- 녹화 상태
- 신호 상태
- 기록 신뢰도/방송실 잔향(서로 다른 형태)

패널, 탭, 진행 막대, 포커스 링, 스캔라인은 CSS/HTML로 유지한다. 장식 이미지를 추가해 자료 열람이나 선택지를 가리지 않는다.

## 6. 파일 배치와 네이밍

권장 제작/런타임 에셋 경로:

    web-game/
      assets/
        environments/
        props/
        characters/
        ui/
        vfx/
          vfx-cctv-atlas-v01.png
          vfx-cctv-atlas-v01.json
        manifests/

파일 이름에는 ID/장소/상태/버전을 사용한다.

- 배경: env-station04-exit02-bg-v01.svg
- 소품: prop-exit02-shutter-closed-v01.svg
- 인물: char-platform-figure-far-v01.svg
- UI: ui-icon-cctv-v01.svg
- VFX: vfx-cctv-atlas-v01.png / .json

기획 데이터는 파일 경로를 직접 조립하지 않고 assetId를 참조한다. 경로와 파일명은 에셋 manifest가 연결한다.

## 7. 제작 승인 체크리스트

- [ ] 세 CCTV 배경이 720×405 기준 좌표와 동일한 원근/안전 영역을 따른다.
- [ ] 한글 텍스트와 카메라 HUD를 그림에 포함하지 않았다.
- [ ] 사건에서 변경되는 문/조명/표지판/인물을 독립 상태로 교체할 수 있다.
- [ ] VFX 시트를 제작했다면 8×6, 128px 프레임 규격과 투명 배경을 따른다.
- [ ] VFX 시트를 제작했다면 메타데이터의 프레임 수, 재생 속도, 앵커, 트리거가 실제 파일과 일치한다.
- [ ] 효과가 CCTV 단서와 대사 가독성을 가리지 않는다.
- [ ] 움직임 줄이기 설정에 정지/비활성 대체 동작이 있다.
- [ ] 아이콘 의미를 텍스트와 함께 전달한다.
- [ ] 외부 원작 IP 로고, 실사 촬영물, 라이선스가 불분명한 폰트를 쓰지 않는다.

이 목록의 우선순위는 첫 번째 에피소드 기준이다. 새 에피소드는 기존 템플릿/소품/VFX를 재사용하고, 새 장면 유형이 추가될 때만 관련 리소스 ID와 장면 데이터 규격을 확장한다.
