# 핵심 루프와 조작

**문서 ID:** GDD-PLY-001 · **버전:** 1.1-review  
**권위 있는 규칙 참조:** [증거·판정·엔딩](../20_systems/증거-판정-엔딩.md)

## 플레이 루프

1. **호출 수신:** 발신 위치, 요청 문구, 사건 제목이 나타난다.
2. **현장 확인:** 기본 CCTV를 본다. 필요하면 다른 카메라를 선택한다.
3. **자료 대조:** 운행표·통화 기록·근무 수칙에서 CCTV 및 호출 내용과 맞지 않는 점을 찾는다.
4. **응답 선택:** 역내 방송 문구를 송출하거나, 방송을 보류하고 선택지에 적힌 업무 처분을 한다.
5. **결과 확인:** 호출 결과와 현장·기록의 변화를 확인한다. 판정은 근무 종료에 공개한다.
6. **다음 호출/결말:** 다음 사건으로 이어지거나 근무 판정을 받는다.

플레이어가 원하는 만큼 자료 화면을 오갈 수 있다. 자료 확인에 제한 시간이나 소모 자원을 두지 않는다. 이는 첫 에피소드에서 플레이어가 공포 규칙을 배울 기회를 보장하기 위함이다.

## 게임 상태

| 상태 | 화면 | 가능한 행동 |
|---|---|---|
| 시작 | 근무 소개와 수칙 | 근무 시작 |
| 사건 조사 | CCTV/운행표/통화 기록/근무 수칙, 호출, 응답 선택지 | 자료 전환, 카메라 전환, 한 번의 응답 선택 |
| 응답 결과 | 선택 결과와 현장 피드백 | 다음 호출로 진행 |
| 근무 결말 | 기록 신뢰도, 잔향, 판정, 선택과 당시 근거 | 같은 근무 재시작 |

한 사건에서 응답이 확정되면 선택지를 잠그고, 결과를 확인한 다음에만 다음 사건으로 진행한다. 이전 응답을 되돌리는 기능은 첫 버전에 포함하지 않는다. 선택으로 생긴 흔적은 근무 종료까지 자료 화면과 로그에 유지한다. 후속 사건의 기본 단서와 충돌하는 일시 현상에는 사라지는 시각과 잔여 흔적을 사건 데이터에 명시한다.

## 입력

| 행동 | 마우스/터치 | 키보드 |
|---|---|---|
| 근무 시작 | 시작 버튼 | Enter |
| 자료/카메라 전환 | 각 탭 버튼 | Tab으로 포커스 이동 후 Enter |
| 응답 선택 | 선택지 버튼 | 포커스가 일반 화면에 있을 때 1, 2, 3 |
| 다음 호출 | 다음 호출 버튼 | 다음 호출 버튼에 포커스 후 Enter |
| 근무 재시작 | 재시작 버튼 | 재시작 버튼에 포커스 후 Enter |
| 효과음 켜기/끄기 | 음향 버튼 | Tab으로 포커스 후 Enter |

키보드 단축키는 포커스된 버튼·링크·입력 요소의 기본 동작을 방해하지 않아야 한다. Enter는 현재 포커스된 버튼을 우선 실행하고, 다음 호출 버튼에 포커스가 있을 때만 진행한다. 사건 전환 시 포커스는 호출 제목으로 안내한 뒤 첫 자료 탭으로 이동할 수 있게 한다. 터치 화면에서 선택지와 탭은 충분히 큰 누름 영역을 제공한다.

## 호출 템포

- 화면에 먼저 호출을 제시하고, 플레이어가 자료를 확인할 여유를 준다.
- 기본 피드에는 그 호출과 가장 관련 있는 CCTV를 자동 선택한다.
- 응답 직후에는 선택이 만든 현상을 보여 준다. 정답/오답 색상이나 점수 변화는 이 시점에 공개하지 않는다.
- 결과를 본 뒤 다음 호출을 기다리는 짧은 공백을 둔다. 자동으로 바로 넘어가지는 않는다.
- 시각 표시는 서사 시간이다. 현재 기획에서는 카운트다운, 시간 초과, 대기 중 적의 행동을 넣지 않는다.

## 정보 접근 원칙

각 호출의 결론은 다음 중 하나로 정리한다.

- 자료가 같은 사실을 확인하므로, 그 사실을 방송한다.
- 자료가 서로 모순되면 정해진 안전·업무 문구가 있는지 확인하고, 없다면 방송을 보류한다.
- 안전 안내처럼 사실 확인 뒤 필요한 행동을 짧게 방송한다.
- 출처가 불가능하거나 인물 정보가 기록과 충돌하고 검증 가능한 방송 문구도 없으면 방송을 보류하고 기록한다.

‘방송 보류’에는 통화 종료나 내선상 확인 요청이 포함될 수 있지만 역내 송출은 없다. 사건별 판단 기준과 선택지의 실제 출력 채널은 [첫 번째 근무 구성](../30_content/episode-01.md)과 각 콘텐츠 데이터에서 관리한다.
