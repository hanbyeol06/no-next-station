# 참고 문서 보관 기준

이 폴더는 정본 GDD의 요구사항이 아니라, 설계가 만들어진 배경과 이전 분석을 보존한다.

## 보관 문서

- [프로토타입 역기획 기준선](superseded/게임-역기획서.md): 당시 구현에서 확인한 동작을 기록한다.
- [초기 데이터 확장안](superseded/데이터-기반-콘텐츠-확장-기획.md): 데이터 분리 방향을 처음 제안한 문서다.

위 문서가 현재 정본과 충돌하면 [게임 기획 문서 목차](../README.md)와 그 아래 00–50 문서가 우선한다. 이전 문서는 필요할 때만 변경 이력 및 출처 확인에 사용한다.
