# 증거·판정·엔딩 시스템

**문서 ID:** GDD-SYS-001 · **버전:** 1.1-review  
**관련 문서:** [핵심 루프](../10_gameplay/core-loop.md), [콘텐츠·데이터 구조](../30_content/content-architecture.md)

## 조사와 증거

각 호출에는 응답 전에 열람 가능한 **서로 다른 출처의 결정적 자료 두 개 이상**을 둔다. 호출자의 말은 검증할 주장이지 그 자체로 정답 증거가 아니다. 자료에는 관측/작성 시각, 출처, 예정·완료·취소 같은 상태를 함께 표시한다. 오래된 기록과 현재 CCTV가 충돌할 때는 사건 문서에 그 충돌을 해석할 근거를 따로 적는다. 정답에 필요한 정보는 선택 이후에 처음 나타나면 안 된다.

첫 근무의 자료 종류는 CCTV, 운행·시설 기록, 통화 로그, 근무 수칙 카드, 현장 메모/센서다. 자료별 절대 신뢰도 숫자는 보여 주지 않는다. 플레이어는 출처와 시각, 서로의 일치 여부를 대조한다.

## 응답과 기록

한 호출에는 정확히 세 선택지가 있고, 각 선택은 한 번만 확정한다. 선택의 `channel`은 다음 둘 중 하나다.

| 채널 | 실행 의미 |
|---|---|
| `broadcast` | 선택 문장을 역내 방송으로 송출한다. |
| `withhold` | 역내 방송을 하지 않는다. 선택지에 적힌 통화 종료·보류·현장 확인 요청과 근무 기록을 한 번에 처리한다. 추가 조작은 없다. |

`withhold`도 적극적인 업무 처분이다. “침묵”은 역내 방송을 하지 않는다는 뜻이며, 기록이나 내선상 확인 요청까지 금지한다는 뜻은 아니다. 선택지 문구는 플레이어가 실제로 하는 일을 모두 드러내야 한다. `broadcast` 선택지를 단순히 발신자에게 답하는 말처럼 작성하지 않는다.

모든 선택지는 고유 ID, 채널, 표시 문구, 판정, 점수 변화, 즉시 피드백, 남는 흔적, 근무 로그 문구를 가진다. 첫 근무에서 각 호출은 기준에 맞는 선택지 하나와 기준 밖 선택지 둘을 가진다. 기준은 [에피소드 01](../30_content/episode-01.md)에 고정한다.

## 세션 변수와 적용 순서

| 변수 | 첫 근무 규칙 |
|---|---|
| 기록 신뢰도 `recordTrust` | 0에서 시작. 기준에 맞는 선택마다 +1, 그 외 +0. 범위 0–5. |
| 방송실 잔향 `echo` | 0에서 시작. 선택별 `echoDelta` 0–2를 더하고 4에서 표시·판정 상한을 적용. 기준에 맞는 마지막 방송도 +1이므로 정답 수와 단순한 반대값이 아니다. |
| 선택 로그 | 호출 ID, 선택지 ID, 표시 시각, 근무 내 순서, 판정, 실제 점수 변화와 결과를 기록. 실제 벽시계 시각을 생성하지 않는다. |
| 장면 흔적 | 선택이 만든 화면/기록 상태를 호출이 바뀌어도 유지한다. 후속 사건이 이를 해소할 때는 전환과 잔여 흔적을 명시한다. |

선택 확정 시 **판정 → 점수/흔적 적용 → 결과 표시 → 다음 호출 버튼 활성화** 순으로 처리한다. 같은 선택을 중복 적용할 수 없다. 현재 호출의 조사 자료는 응답 전부터 보이며, 이전 호출의 흔적은 자료를 거짓으로 바꾸지 않고 별도 상태로 표시한다. 재시작하면 모든 세션 변수와 흔적을 초기화한다.

## 결말 판정

다섯 호출을 마친 뒤 다음 순서로 결말 하나를 선택한다.

| 우선순위 | 조건 | 판정 | 결말 톤 |
|---:|---|---|---|
| 1 | `recordTrust ≤ 2` 또는 `echo ≥ 4` | 미귀가 | 출입 기록에는 입실만 남는다. |
| 2 | `recordTrust = 5` 그리고 `echo ≤ 1` | 정상 | 퇴근 처리 후 안내판에 근무 번호가 나타난다. |
| 3 | 그 외 전부 | 보류 | 퇴근 후에도 다음 근무자를 부르는 목소리가 남는다. |

조건은 위에서부터 평가한다. 첫 근무에서 0–5 신뢰도와 0–4 잔향의 모든 조합에 정확히 하나의 결말이 있어야 한다. `echo`가 상한에 도달한 뒤에도 선택 로그에는 원래 `echoDelta`를 보존하고, 결말에는 실제 누적값을 쓴다. 정상 결말에도 불길한 여운은 남지만 업무 판정은 성공이다.

## 피드백 공개 시점

- 조사 중에는 호출 진행만 표시한다. 신뢰도, 잔향, 정답 색상은 표시하지 않는다.
- 응답 직후에는 **무엇이 일어났는지**를 문장과 해당 자료 화면에 보여 준다. “정답/오답”, 점수 변화, 빨강/초록 판정 색은 표시하지 않는다. 화면 변화가 없는 선택은 통화/근무 기록의 변화를 보여 준다.
- 근무 종료 화면에서 신뢰도, 잔향, 판정과 호출별 기록 일치 여부를 공개한다. 재도전할 수 있도록 선택 당시 사용 가능했던 근거를 로그에서 다시 볼 수 있다.
- 음향은 분위기와 추가 피드백이다. 소리를 끈 상태에서도 모든 단서와 선택 결과를 읽을 수 있어야 한다.

## 데이터로 표현할 수 있는 범위

첫 버전의 공통 평가기는 선택지 ID 비교, AND/OR 조건, 점수 범위, 상태 플래그, 점수 변경, 로그 작성, 사전 등록된 장면 효과를 처리한다. 새 상호작용이나 자료 종류가 필요하면 런타임 기능과 검증 규칙을 먼저 추가한다. 사건별 정답이나 효과를 배열 번호, 화면 제목, `wrong` 참거짓으로 분기하지 않는다.
